# DSH frame

> **简介**：一个独立的 Electron 桌面应用，驱动**你自己安装的官方 DeepSeek Harness**，这个应用尽可能的不对官方harness做任何修改，只提供显示窗口。
>
> **适合谁**：已经装了官方 `dsh`、受够了每次开浏览器找标签页、并且希望在插件损坏harness时能便捷解决的人。

---

## 它解决什么

**1. 不用再开浏览器。** 
双击桌面图标就是应用窗口，无地址栏、有任务栏图标、有托盘。官方 Web UI 一个像素都不改——它是**另一个视口**，不是被注入 CSS 的页面，还有沉浸式标题栏。
<img width="1156" height="779" alt="屏幕截图(1283)" src="https://github.com/user-attachments/assets/de35f590-c606-45c4-a5a4-136333739ffa" />

**2. 自动拉起和管理服务。** 
- 启动时如果已有自己上次启动的服务 → **直接复用**，不重复起第二个
- 关窗口 = 退出应用，但**服务留在后台**，下次启动秒开
- 托盘选择「退出并停止服务」应用和服务一起退出，解决忘记关服务服务一直后台运行问题
- 服务异常退出 → 可以一键重启

**3. 救砖功能** 当你安装了过时或不兼容的插件时，此时应用显示的不是黑屏也不是一堆栈，而是提供你关闭插件的选项：

<img width="878" height="596" alt="屏幕截图(1280)" src="https://github.com/user-attachments/assets/5d24e9ac-13b2-4ac2-81b0-07a738d5730e" /> <img width="878" height="592" alt="屏幕截图(1281)" src="https://github.com/user-attachments/assets/9b780649-82bb-4f68-8717-e782f0a97aca" />

「禁用」是把名字从 `dsh.profile.bundles` 里去掉、**插件仍然装着，只是这次启动不加载**，可逆、不需要 pnpm、不需要联网。
## 修改内容
- **拦截dsh market自重启**：dsh market会"先起一个新服务再杀死这个服务"，在外壳下会多出一个服务；应用在这个服务结束后会尝试重连，而市场拉起的服务应用不会识别，从而拉起一个新服务，导致后台有两个dsh服务。
  应用默认会使用dsh market的内置功能取消它的重启功能，你需要在标题栏的重启按键上手动重启。当然，你也可以在托盘图标那里关掉这个功能
- ## 快速开始

**前置**：已安装官方 DeepSeek Harness 与 Node（^22.19 或 >=24）。没有的话：`npm i -g @deepseek-ai/dsh`。
1. 运行 `DSH Setup 0.1.0.exe` 安装（自动建桌面与开始菜单快捷方式），或
2. 直接运行 `DSH-portable-0.1.0.exe`（免安装）
