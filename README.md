# DSH frame

> **简介**：一个独立的 Electron 桌面应用，驱动**你自己安装的官方 DeepSeek Harness**——不捆绑运行时、不打补丁、不改你的 profile。
>
> **适合谁**：已经装了官方 `dsh`、受够了每次开浏览器找标签页、并且希望插件把 profile 搞坏时能在界面里自救的人。

---

## 它解决什么

**1. 不用再开浏览器。** 双击桌面图标就是应用窗口，无地址栏、有任务栏图标、有托盘。官方 Web UI 一个像素都不改——它是**另一个视口**，不是被注入 CSS 的页面。

**2. 进程状态不再是一笔糊涂账。** 应用托管服务生命周期：

- 启动时已有自己上次启动的服务 → **直接复用**，不重复起第二个
- 关窗口 = 退出应用，但**服务留在后台**，下次启动秒开
- 托盘「退出并停止服务」连进程树一起收干净
- 服务异常退出 → 失败页给你一键重启

**3. 插件搞坏 profile 时能自救。** 这就是最要命的场景：某个插件 import 了一个官方包不存在的导出，**整个 profile 都起不来**，包括插件市场自己的页面（它的源码里就写着这句话）。此时应用显示的不是黑屏也不是一堆栈，而是：

```
启动失败
┌────────────────────────────────────────┐
│ 完整错误日志…                            │
└────────────────────────────────────────┘
      [ 重启 DSH 服务 ]   [ 打开插件列表 ]

插件列表：
  dsh-neu-theme    ^0.1.1   已启用   日志指向它   [禁用]   ← 整行标红
  dshmarket        ^1.45.1  已启用                [禁用]
  @deepseek-ai/dsh-base               官方 bundle
```

「禁用」是把名字从 `dsh.profile.bundles` 里摘掉、**依赖仍然装着**，可逆、不需要 pnpm、不需要联网。
## 功能清单

- **沉浸式标题栏**：紧贴系统三键左侧一个重启键（46×36，与原生按钮同框同符号色）；帧的底色**取样自官方页面的真实背景**，侧边栏的颜色延续进标题栏，明暗自动跟随
- **服务生命周期**：优先复用、关窗即退而服务常驻、单实例、托盘可显示/重载/重启/停止
- **拦截插件市场自重启**：市场会"先起一个替换进程再自杀"，在外壳下会多出一个服务；应用在**每次拉起服务前**把 `dsh-market.allowRestart` 断言成 `false`（市场自己的官方开关，路由会返回 403）。托盘的「允许插件市场自重启」是唯一放行口，**检测不到市场就不显示这一项**
- **启动失败恢复**：失败页 → 插件列表（日志点名的标红）→ 禁用/启用 → 重启；profile 读不出来时只显示重启
- **诊断入口**：`--dsh-selftest`（只验 runtime 与服务）、`--dsh-probe-ui`（开窗后报告渲染结果）、`--dsh-probe-recovery`（驱动恢复界面）、`--dsh-quit`（让运行中的实例退出）
- ## 快速开始

**前置**：已安装官方 DeepSeek Harness 与 Node（^22.19 或 >=24）。没有的话：`npm i -g @deepseek-ai/dsh`。

**用**：

1. 跑 `DSH Setup 0.1.0.exe` 安装（自动建桌面与开始菜单快捷方式），或
2. 直接跑 `DSH-portable-0.1.0.exe`（免安装），或
3. 指向仓库里 `dist-2\win-unpacked\DSH.exe`
